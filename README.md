# Machi Koro Case
В данном репозитории находится реализация кейса по настолке "Machi Koro".

В его рамках были реализованы:
1. Базовые механики в core
   1. Процесс шага
   2. Архитектура для приёма ввода от игроков
   3. Хранение данных игр в двух форматах: JSON и SQL(используется Exposed)
   4. Механика карт
2. CLI интерфейс для игры
3. GUI интерфейс для игры используя Compose Multiplatform
